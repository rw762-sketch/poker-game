# River Room

A browser-based Texas Hold’em game against three computer opponents. Play chips only.

## Play

https://rw762-sketch.github.io/poker-game/

## Features

- Full betting rounds, rotating blinds, all-ins, side pots, and split pots
- Best-five-of-seven hand evaluation
- Responsive table and built-in rules

## Run locally

Run `python3 -m http.server 4173` in this folder and open http://localhost:4173.

State lasts for the current page session. Opponents use simple automated strategies.
